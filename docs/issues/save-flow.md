## 목표

새 게임·이어하기를 명확히 구분하고 저장 실패와 복구 여부를 사용자가 알 수 있게 한다.

저장 버전 복구, 손상된 값 정리, 저장 접근 실패의 세션 대체 처리가 추가되었다. 완전한 타이틀·이어하기 UI는 별도 작업이다.

## 완료 조건

- [ ] 타이틀에서 유효 저장의 날짜와 이어하기 제공
- [ ] 새 게임 및 초기화에 기존 진행 삭제 확인 제공
- [ ] 저장 실패 시 자동 저장 성공으로 표시하지 않음
- [ ] 손상된 저장 복구 안내와 재시작 경로 제공
- [ ] 저장 실패 중에도 현재 세션의 진행 가능
- [ ] 복구·초기화·엔딩 후 재시작을 브라우저에서 검증
