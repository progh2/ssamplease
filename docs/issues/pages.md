## 목표

정적 빌드를 GitHub Pages에 배포하고 실제 배포 URL에서 새 게임과 이어하기를 검증한다.

배포 워크플로와 Vite 상대 경로 설정이 있다. 원격 저장소 연결과 실제 배포 성공은 별도 확인이 필요하다.

## 완료 조건

- [ ] 원격 저장소와 Pages의 GitHub Actions 소스 설정 확인
- [ ] 테스트·빌드 성공 후 배포 작업 성공
- [ ] 저장소 하위 경로에서 에셋 404 없이 실행
- [ ] 배포 URL 새로고침 후 진행 유지
- [ ] 데스크톱·모바일 배포 URL 플레이 결과와 링크 기록
