## 목표

15일을 채운 확인 버튼 중심 업무를 문서·규칙 비교와 선택에 따른 결과가 있는 플레이로 개선한다.

## 완료 조건

- [ ] DAY 1~3 가정통신문 원문과 채점 기준·답안을 직접 비교
- [ ] 반복 업무에 규칙과 예외 데이터를 분리하고 1~3일 변칙 적용
- [ ] 출결 연락 절차와 후속 사유가 실제 학생 기록에 연결
- [ ] 기안 금액·예산·첨부·결재 조건을 검증하고 보완 가능
- [ ] 시험 감독·OMR의 수량과 누락을 직접 확인
- [ ] 상담 선택과 후속 반응을 기록하고 엔딩에 반영
- [ ] 모든 실수 경로에서 재시도 또는 절차상 처리 후 진행 가능
- [ ] 수업과 시험 준비의 날짜·교실·학생 수 불일치 점검

새 날짜를 늘리기보다 DAY 1~3 품질을 먼저 확인한 후 나머지 날짜에 확장한다.
