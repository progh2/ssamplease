# 검토 후 개선 기록

## 이번 변경

- 저장 데이터 복구: 이전 버전 진행 보존, 손상된 JSON/접근 제한/용량 오류 대응, 저장 실패 안내.
- 진행 규칙: 엔진에서 필수 업무 미완료 시 날짜 이동 거부, 중복·알 수 없는 업무 완료 거부.
- 시간표: 날짜별 교시·교실 데이터와 교실 이동, 다음 수업 순서 준수, 완료 후 교무실 복귀.
- 기안: 수량과 예산 검증, 제출 이력, 다음 날짜 보완 메시지, 첨부 후 재제출, 승인 및 집행 확인.
- 첫 3일: 가정통신문 3장 확인, 서명 누락·학번 불일치 보완, 기준표 기반 점수 입력과 재시도.
- 콘텐츠 검증: 스키마와 참조, 선행 조건 순환, 미래 의존, 교시 충돌 검증.
- PC·모바일 브라우저 회귀 테스트 도입.

## 남은 작업

- 영어 이야기 번역 완성과 모든 표시 문자열의 번역 키 통합.
- DAY 6~15 출결·상담·시험 감독·OMR의 개별 자료 및 선택 결과 보강.
- 메신저 읽음 상태와 업무 수락 상태 분리, 상담 선택·신뢰도 기록.
- PRD 원문 문서화, 챕터·이벤트·변칙 JSON 분리 확대.
- 타이틀/이어하기와 하루 결과 화면, 키보드·스크린리더 접근성 검증.
- 초기 번들 분리 및 에셋 연출 개선.
- GitHub Pages 배포 설정 및 배포 URL 검증.

단위 테스트 통과는 전체 브라우저 완주를 의미하지 않습니다. 자동 브라우저 테스트 범위는 첫 3일 및 기안/저장 시나리오이며, 15일 완주는 상태 엔진 테스트에서 확인합니다.

## 로컬 검증 결과

- 단위 테스트 21개 통과, TypeScript 및 프로덕션 빌드 성공.
- PC·모바일 Chromium 각각 첫 3일 완주 및 오답 수정, 손상 저장 복구 통과(4개).
- 수량 변경·예산 초과 차단·제출·보완 첨부·재제출·새로고침 복원 통과(2개).
- 외부 Google Fonts 요청 제거: 기본 글꼴로 오프라인에서도 즉시 표시.
- 이슈 등록 스크립트 구문 검사와 로컬 dry-run 통과. 이후 실제 CLI 실행에서 발견한 `--slurp`/`--jq` 동시 사용 문제를 수정하고 이슈 5개 등록 완료.
