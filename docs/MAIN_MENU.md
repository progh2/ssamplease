# 시작 화면과 플레이어 설정

- 처음 접속하면 타이틀 화면. 저장이 없으면 이어하기 비활성화.
- 새 게임은 첫날 책상에서 시작. 저장이 있으면 교체 여부를 확인하고 취소 가능.
- 이어하기에는 저장 날짜·처리한 업무 수를 표시하며 작업 중 도장·입력도 복원.
- 플레이 중 메뉴 버튼으로 일시정지·설정·타이틀 복귀. 메뉴가 열리면 배경 조작 차단.
- 설정: 한국어/영어, 글자 크게 보기, 화면 움직임 줄이기. 이야기와 별도로 저장.
- 기존 교실 픽셀아트와 따뜻한 패널 사용. PC 두 열, 모바일 한 열 구성.

배포는 검사·빌드와 Pages 게시를 별도 job으로 분리한다. 배포 파일 이름에 실행 ID/시도 번호를 넣어 재실행 중 중복을 방지한다. 업로드 메타데이터를 조회한 후 배포하며, 배포만 실패할 경우 검사 전체를 다시 돌리지 않고 재시도할 수 있다.
