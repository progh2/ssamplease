# 수업 참여 활동 확장

기존의 규칙 선택·예제 실행·이해 확인 뒤에 날짜마다 다른 학생 참여 활동을 추가한다. 활동은 `src/content/lessonLabs.json`에서 관리하며 한국어·영어를 함께 정의한다.

| 날짜 | 학생 활동 | 판단 요소 |
|---|---|---|
| 1 | 급식 로봇 명령 정리 | 목표에 필요한 단계와 불필요한 반복 |
| 2 | 방송 예약표 예측 | 시작 포함·종료 제외 경계값 |
| 3 | 반복문 추적표 | 반복 횟수와 누적 합의 차이 |
| 4 | 방송 고장 증거 대조 | 관찰로 지지되는 결론과 불확실한 추측 |
| 6 | 학급 통계 익명화 | 전체 집계와 개인 식별 정보 |
| 8 | 학급 앱 권한 회의 | 목적에 맞는 공유와 잘못된 공유의 수정 |
| 9 | 동아리 장보기 계산 | 단가·수량·총액·예산 비교 |
| 15 | 학생 해결안 발표 | 검증한 결론과 추가 확인이 필요한 주장 |

카드와 판단 버튼은 터치로 조작한다. 틀린 분류는 해당 카드의 구체적 근거를 보여주며 수정 가능하다. 입력·선택한 카드·검토 결과는 자동 저장되고, 활동 결과를 수업 기록에 반영해야 수업을 마칠 수 있다. 기록된 학생 반응은 활동 주제별로 다르다.

기존 8개 수업을 통한 Playwright 검증에 각 참여 활동의 오답→수정→결과 반영을 추가했다. 영어 진행도 같은 데이터의 영어 항목으로 검증한다. 콘텐츠 검사는 모든 수업의 활동 존재 여부, 카드 목적지, 번역, 활동 종류의 다양성을 확인한다.
