# 게임 방향 재설계 — 작은 사건이 쌓이는 교사 생활

## 문제

정확한 절차를 계속 검사하면서 긴 설명 → 정답 선택 → 검증을 반복했다. 메신저에도 목적·수신처·첨부를 매번 시험해 대화가 국어 시험처럼 됐다. 검사 개수는 재미의 증거가 아니다.

## 목표 경험

“책상에서 몇 가지를 만지고, 동료와 웃고, 작은 사고를 수습하다 보니 내 자리가 생겼다.”

재미는 세 축으로 만든다.

- 손맛: 도장, 종이 분류, 케이블, 다이얼 등 직접 조작과 즉시 보이는 반응.
- 사람: 짧은 대화와 표정·농담·도움 요청. 말투에 따른 다른 반응이며 모두 진행 가능한 선택.
- 성장과 발견: 업무와 함께 책상 물건·인물 사연이 쌓이고 이후 사건에서 다시 등장.

## 하루 구성

필수 중심 사건 하나 + 짧은 생활 업무 + 선택적 수다/보너스 활동. 한 업무 안에 여러 단계의 시험을 계속 중첩하지 않는다. 실제 시간제한은 유지하지 않는다. 대사 한 덩어리는 1~2문장, 설명은 필요할 때만 펼친다. 정확한 업무 절차는 분위기를 지탱하는 배경이며 매번 재시험하지 않는다.

실수는 짧은 수습 사건이나 인물 반응으로 이어지고 재시도할 수 있다. 점수 감점·정답 도달만이 결과가 되지 않는다. 갈등은 숨은 정답 찾기보다 “도움을 요청할까, 먼저 해볼까” 같은 접근 차이로 만든다. 업무를 무한히 추가하지 않는다.

## 이번에 실제 적용한 범위

- 메신저 11개 대사를 짧은 학교생활 대화로 교체. 목적·수신처·필수 첨부 검사·본문 작성 양식을 제거.
- 매 대화에 모두 유효한 답장 두 개. 즉시 내 말풍선과 선택별 상대 반응이 등장하고 후속 업무 진행. 정답 판정 팝업 제거.
- 첫날 서류: 잉크 색을 고르고 서류를 눌러 도장을 찍은 뒤 처리함으로 넘김. 선택한 색과 진행 저장. 서류별 학생 한마디와 접수 도장 표시.
- 수업 추가 활동: 기본 이해 확인 후 여기서 끝내거나 보너스 실습을 선택. 모든 활동을 필수로 누적하지 않음.

## 이후 업무를 바꿀 기준

| 업무 | 중심 재미 | 줄일 요소 |
|---|---|---|
| 채점 | 빨간 펜으로 핵심 오류 찾기, 엉뚱한 학생 답안 | 점수·피드백·후속 수업 정답을 연속 검사 |
| 수업 | 학생 반응을 보며 짧은 활동 운영 | 설명·조건표·전이 문제·추가 실습 필수 중첩 |
| 방송 | 버튼·연결·미터로 소리 살리기 | 장문의 장비 규칙 시험 |
| 기안 | 서류 왕복의 작은 코미디, 빠진 조각 채우기 | 모든 항목 입력·검토를 매번 반복 |
| 출결 | 교실 속 학생 찾기와 짧은 확인 | 학생별 상태+근거를 긴 문서와 매칭 |
| 시험 감독 | 교실 관찰과 학생 요청 수습 | 매 사건마다 지침을 읽어야 버튼 활성화 |

첫날과 메신저부터 변경했으며 다른 업무 전체가 이미 이 방향으로 전환됐다고 주장하지 않는다. 향후 변경은 “재미가 다른 조작이 생겼는가, 읽을 양이 줄었는가, 두 선택이 유효한가”로 검토한다.

## 검증 기준

기능 검사는 진행·저장·모바일·분기 오류에 사용한다. 재미 평가는 짧은 플레이에서 읽는 시간이 조작보다 길지 않은지, 한 업무 뒤 다른 행동이 나오는지, 다음 인물 반응이 궁금해지는지로 판단한다. 실제 플레이어 평가 전까지 재미 완성을 선언하지 않는다.
