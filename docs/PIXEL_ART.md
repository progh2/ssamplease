# Pixel background assets

Created with the built-in image generation tool. These are original generated backgrounds, not photographs of the user's school.

- `src/assets/backgrounds/teacher-desk.png`: empty overhead desktop; interactive objects remain separate.
- `src/assets/backgrounds/classroom.png`: empty classroom facing the board; used in the classroom scene and lesson workspace.

Both assets are bundled by Vite so repository-relative GitHub Pages paths work. Phaser resizes with its container and covers without distorting the image; outer edges may crop on wide screens. The scene height is independent of the task board. Actual staff-room layout is deferred until the user's reference photo arrives.

## Final generation prompts

### Desk

Use case: stylized-concept. Asset type: production background for a warm Korean school teacher life pixel-art game, square image. Draw ONLY an EMPTY teacher desktop from directly overhead, the wooden desktop fills 95 percent of the image, with a thin dark wood desk lip at bottom and subtle pale wall border across very top. Warm honey oak, refined hand-placed pixel clusters, deliberate crisp stepped edges, limited cozy 32-color palette, restrained grain and small signs of wear, late afternoon window light in broad subtle pixelated patches at upper left. High quality 2D indie game environmental pixel art, not photorealistic, not smooth vector, not blurry. The entire central area must remain empty, low contrast and usable for separate interactive object sprites. Single continuous wood veneer desktop, not many floorboards. No objects whatsoever: no computer, no paper, no plants, no pens, no phone, no drawers, no chair, no text, no UI, no border around image. Correct overhead geometry. Polished quiet inviting atmosphere.

### Classroom

Use case: stylized-concept. Asset type: production square background for a Korean high-school teacher life 2D pixel-art game. A quiet empty contemporary Korean high school classroom viewed from back toward front, coherent straight-on perspective. Large blank dark green chalkboard centered upper wall, simple teacher lectern below, orderly three columns of student desks and chairs facing the board, correct chair orientation and consistent table legs, tall windows along left with pale curtains and soft sunlight, modest storage at right. Warm honey oak furniture, cream walls, subdued sage shadows. Premium cozy indie GAME PIXEL ART with crisp visible square pixel clusters and stepped contours, limited harmonious palette, not photo or smooth illustration. Balanced detailed environmental art, fixed camera, clean readable silhouettes, no people, no UI, no text, no lettering, no logos, no floating objects. Board remains blank for dynamic overlay. Compose important classroom elements within central 75 percent so slight edge cropping is safe. Furniture plausible, no drawers visible, no dramatic lens effects.
