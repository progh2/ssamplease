# 핫메신저 사용 경험 개선

기존에는 메신저 탭이 업무 카드 목록과 같고, 읽기 버튼으로 요청이 완료되어 대화·답장·전송 경험이 없었다.

이제 담당자별 대화 목록, 검색, 읽지 않음 표시, 날짜별 받은 메시지, 첨부 미리보기, 수신 대상, 답장 작성과 전송, 상대 회신, 전송·읽음 표시를 제공한다. 완료한 대화는 다시 열 수 있고 날짜가 바뀌어도 남는다. 모바일은 대화 목록과 대화방을 오간다.

학교 업무 연습:

- 선배의 업무 안내 확인 후 답장
- 교무부 평가 요청의 처리 방침 회신
- 방송반 점검 요청 수락
- 행정실에 점검 결과와 점검표를 보내 구매 조건 문의
- 반려 사유서 확인 후 기존 기안의 보완 계획 회신
- 승인 확인 후 시행 공문으로 연결
- 감독표 첨부와 변경 교실 확인
- 검수·집행 완료 확인과 마지막 인사

읽기만으로 필수 요청을 완료하지 않는다. 전송 전 전체 교직원 대화방 오선택, 첨부 미확인, 근거 누락, 확인 없이 완료 보고를 점검하고 수정할 수 있다. 작성 중 내용은 전송되지 않으며 자동 저장된다. 전송이 성공한 시점에 업무 상태와 대화 기록을 함께 저장한다.

답장 의도를 고른 뒤 예시를 넣거나 직접 편집해 전송한다. 의도·대상·첨부·최소 본문을 검증하는 대본 기반 시뮬레이션이며 자유 입력 문장의 의미를 AI로 판독하지 않는다. 실제 외부로 메시지를 보내지 않는다. 예전 저장에서 완료한 대화는 답장을 임의로 복원하지 않고 이전 진행에서 확인했다고 표시한다.

대화 데이터는 `src/content/messenger.json`, 화면은 `src/components/HotMessenger.tsx`에 있다. 기존 업무 완료 저장의 `memories`에 전송 내용을 보관한다. 진행 중인 초안은 기존 `drafts` 저장을 이용한다.

검증: 모든 메시지 업무의 데이터 대응, PC·모바일 각 시나리오의 읽음≠완료, 잘못된 답장·수신처 수정, 첨부 확인, 초안 복원, 전송 후 대화 복원. 기존 첫 3일 진행 및 승인 공문 선행 흐름도 새 답장 방식으로 검증한다.
