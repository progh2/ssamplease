# 미니게임 개선 루프 — 2026-11-20

## 확인 기준

재미를 테스트 통과만으로 보장하지 않는다. 이번 검토에서는 다음 조건을 플레이 가능한 기반의 기준으로 삼았다.

1. 메시지 읽기를 제외한 모든 필수 업무에 별도 작업 화면이 있다.
2. 관찰하거나 대조할 근거가 있고, 플레이어의 판단이 결과를 바꾼다.
3. 그럴듯한 오답에도 구체적 피드백과 복구 경로가 있다.
4. 같은 업무가 반복될 때 날짜별 내용이나 예외가 다르다.
5. 수업 방식·상담 지원·구매 수량처럼 둘 이상의 유효한 선택이 존재한다.
6. 완료 이후의 선택이 다음 수업·상담·공문에 실제로 반영된다.
7. 중간 저장·언어 변경·터치 조작이 진행을 막지 않는다.
8. 시간제한 없이 처리 완료한 업무만 퇴근 조건에 반영한다. 공동 검토·확인 중도 합법적인 완료 경로다.

## 1회차: 기존 흐름 검토와 재설계

발견: 모든 수업의 같은 덧셈 퍼즐, 한 번의 점수 선택, 후기 채점·상담·감독 단일 버튼, 실제로 변하지 않는 ACC 표시, 날짜를 넘기면 사라지는 대화 선택.

수정:
- 수업 8개: 순서·경계값·반복·방송·출결·공개 범위·예산·마지막 성찰. 실행 결과로 수정하고 새로운 상황의 이해까지 확인한다.
- 서류 2묶음: 누락 필드 표시와 보완 사유. 비동의는 누락이 아니며 공개 제한으로 정상 접수한다.
- 채점 4묶음: 각각 학생 3명의 기준별 점수·피드백·공동 검토. 수업 메모가 이후 수업의 시작 활동으로 이어진다.
- 상담: 학생 경험·점검 기록·바람을 듣고 리허설/동료/휴식 중 지원 계획 선택. 14일 차에 약속별 후속 대화.
- 감독 3일: 좌석 관찰·관련 지침·조치·기록·인계. 눈길만으로 부정행위를 단정하지 않는다.
- 선택 기억은 유효한 업무 완료 때 한 번만 저장한다. 과거 저장에서 선택을 임의 추정하지 않는다.

## 2회차: 실제 조작과 시뮬레이션 연결

발견: 1개 구매 후 공문은 2개로 고정, 승인 확인 전에 공문 처리 가능, 케이블 순서만 바꿔 손상이 고쳐짐, 출결 3명만 보이는데 총원 28명 설명 없음, 자료 정리 단일 클릭, OMR 반복 변칙 부족.

수정:
- 구매 수량은 모든 단계에서 동일. 승인 메시지가 시행 공문의 선행 조건.
- 예산 계정·결재선·점검표를 선택하고, 보완 시 같은 규격의 견적 비교.
- 케이블 연결 + 예비품 교체 + 출력 레벨 + 시험 방송 후 임시 복구 기록.
- 출결 4종: 추가 대조 3명 + 정상 확인 25명으로 명확히 구분. 문서와 상태를 짝짓고 합계를 확인한다.
- 감독 일정/배부 묶음/시험 자료를 카드별 분류하고 재대조한다.
- OMR은 기본 확인 → 성명 누락 → 학번 누락으로 변칙을 나눈다. 원본 답안은 수정하지 않는다.
- 하늘의 학번을 문서·채점·출결에서 일치시켰고, 결석일 상담은 방과 후 원격 상담으로 명시했다.

## 3회차: 저장·모바일·회귀 확인

발견: 모바일 채점의 긴 기준표가 기본 fieldset 최소 폭 때문에 화면 밖으로 밀림. 회귀 테스트에서 완료 카드와 돌아가기 버튼의 중복 이름을 잘못 선택.

수정: 작업 필드의 최소 폭 해제와 모바일 한 열 배치, 작업 영역을 한정하는 테스트 선택자. 출결의 복원된 검토 상태도 실제 입력을 다시 검증해 불완전한 저장으로 요약 화면이 깨지지 않게 했다.

검증 방법: Vitest의 상태·데이터·미래 기억·중복 완료 검증, Playwright의 PC/모바일 실제 조작, 오답→수정, 중간 새로고침, 구매 연속성, 상담 약속의 후속 대화, 8개 수업, 후기 채점, 출결·감독·분류 시나리오. 별도로 실제 화면을 캡처해 글자·버튼·배경·가로 넘침을 확인한다.

## 남은 평가 범위

외부 플레이어의 재미·피로도 평가는 아직 없다. 근거 대조가 많은 게임이므로 실제 플레이 피드백으로 적절한 업무 수와 설명 분량을 조정해야 한다. 기존 일부 이야기의 영어 번역, 책상 물건 SVG, 타이틀/이어하기 화면은 별도 이슈 범위다. 이번 변경은 생성한 방송실 배경과 학생 초상화를 사용하지만 모든 물건의 픽셀아트 교체를 주장하지 않는다.

## 저장 호환성

저장 버전 8. 완료 기록과 날짜는 유지한다. 구형 단순 채점·수업의 미완료 입력은 새 규칙에 맞지 않으면 해당 작업의 시작으로 돌아가며, 다음 날 이야기 선택은 새 플레이에서 완료한 기록만 사용한다. 오류 메시지 자체는 일시적이고 판단에 필요한 입력은 저장된다.

## 로컬 검증 결과

- 단위·콘텐츠·저장 테스트 41개 통과, TypeScript 및 production build 통과.
- PC/모바일 64개 브라우저 사례 중 62개가 전체 실행에서 통과. 나머지 2개는 별도 검사와의 trace 출력 경로 충돌(ENOENT)로 종료 단계에서 실패했고, 실행을 분리한 재검사에서 모두 통과했다. 기능 오류로 처리한 것이 아니며 CI에서는 전체를 한 번에 실행한다.
- 마지막 추가한 기존 채점 기록 → 후속 수업 활동 연결도 PC/모바일 별도 검사 2개 통과.
- 실제 모바일 채점 화면에서 작업 영역 `clientWidth = scrollWidth = 393` 확인. 기준표 열기·닫기 후 첫 답안 채점과 다음 답안 이동 확인.
- 상담 PC, 채점 PC/모바일, 감독 모바일을 캡처해 시각 검토. 모바일에서는 중복 업무 설명을 줄이고 명부·채점 기준표를 접어서 답안을 먼저 볼 수 있게 보완했다.
